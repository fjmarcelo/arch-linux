\section{Particionado del disco}

En este paso dividiremos el disco en particiones. Usaremos \tmarron{cfdisk},
una herramienta interactiva más intuitiva que \texttt{fdisk} para quienes se acercan por primera vez.

\begin{tcolorbox}[colback=blue!5, colframe=blue!50!black, title={\faInfoCircle\hspace*{0.5em} Identificar el disco antes de empezar}]
\begin{lstlisting}[style=bashstyle]
lsblk
\end{lstlisting}
El nombre del dispositivo depende del tipo de unidad:
\begin{itemize}
  \item \textbf{SATA} (disco mecánico o SSD): \texttt{/dev/sda} — particiones: \texttt{/dev/sda1}, \texttt{/dev/sda2}\ldots
  \item \textbf{NVMe} (unidad M.2): \texttt{/dev/nvme0n1} — particiones añaden \texttt{p}: \texttt{/dev/nvme0n1p1}, \texttt{/dev/nvme0n1p2}\ldots
\end{itemize}
\end{tcolorbox}

Abre \tmarron{cfdisk} con el nombre que corresponda a tu disco:

\begin{tcolorbox}[title=Abrir cfdisk]
\begin{lstlisting}[style=bashstyle]
cfdisk /dev/sda        # SATA
cfdisk /dev/nvme0n1    # NVMe
\end{lstlisting}
\end{tcolorbox}

\subsection{Flujo de trabajo en cfdisk}

Al abrir \tmarron{cfdisk} en un disco vacío se pedirá el \textbf{tipo de tabla de particiones}:
\begin{itemize}
  \item \textbf{gpt} — Para sistemas \textbf{UEFI} (hardware moderno, recomendado).
  \item \textbf{dos} — Para sistemas \textbf{BIOS legacy}.
\end{itemize}

Una vez dentro, el flujo para crear cada partición es el siguiente:
\begin{enumerate}
  \item Seleccionar \texttt{Free space} con las teclas ↑↓.
  \item Elegir \textbf{[ New ]} y pulsar \texttt{Enter}.
  \item Introducir el \textbf{tamaño} (ej.\ \texttt{512M}, \texttt{4G}, \texttt{100G}).
  \item Elegir \textbf{[ Type ]} y asignar el tipo correcto:
    \begin{itemize}
      \item Partición EFI → \textit{EFI System}
      \item Raíz o home → \textit{Linux filesystem}
      \item Swap → \textit{Linux swap}
    \end{itemize}
  \item Repetir para cada partición del esquema.
  \item Elegir \textbf{[ Write ]}, escribir \texttt{yes} y luego \textbf{[ Quit ]}.
\end{enumerate}

\begin{tcolorbox}[colback=orange!8, colframe=orange!70!black,
  title={\faExclamationTriangle\hspace*{0.5em} Los cambios no se graban hasta Write}]
Puedes rediseñar el esquema libremente. Solo se aplican al disco físico
al confirmar con \textbf{Write}.
\end{tcolorbox}

\subsection{Formatear y montar las particiones}

\begin{tcolorbox}[title=Formateamos las particiones (GPT+EFI — SATA)]
\begin{lstlisting}[style=bashstyle]
mkfs.fat -F32 /dev/sda1   # EFI
mkfs.ext4 /dev/sda2        # raiz
mkswap /dev/sda3           # swap
mkfs.ext4 /dev/sda4        # home
\end{lstlisting}
\end{tcolorbox}

\begin{tcolorbox}[title=Formateamos las particiones (GPT+EFI — NVMe)]
\begin{lstlisting}[style=bashstyle]
mkfs.fat -F32 /dev/nvme0n1p1   # EFI
mkfs.ext4 /dev/nvme0n1p2        # raiz
mkswap /dev/nvme0n1p3           # swap
mkfs.ext4 /dev/nvme0n1p4        # home
\end{lstlisting}
\end{tcolorbox}

\begin{tcolorbox}[title=Montamos en \texttt{/mnt} — SATA]
\begin{lstlisting}[style=bashstyle]
mount /dev/sda2 /mnt
mount --mkdir /dev/sda1 /mnt/boot
mount --mkdir /dev/sda4 /mnt/home
swapon /dev/sda3
\end{lstlisting}
\end{tcolorbox}

\begin{tcolorbox}[title=Montamos en \texttt{/mnt} — NVMe]
\begin{lstlisting}[style=bashstyle]
mount /dev/nvme0n1p2 /mnt
mount --mkdir /dev/nvme0n1p1 /mnt/boot
mount --mkdir /dev/nvme0n1p4 /mnt/home
swapon /dev/nvme0n1p3
\end{lstlisting}
\tcblower
\scriptsize Verifica con \texttt{lsblk} que las particiones aparecen montadas en sus puntos correspondientes.
\end{tcolorbox}
