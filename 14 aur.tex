\section{Repositorio AUR}
\subsection{Introducción}

	El \textbf{Arch User Repository (AUR)} es un repositorio comunitario para usuarios de Arch.\vspace{5mm}

	Contiene descripciones de paquetes (PKGBUILDs) que permiten compilar un paquete desde el código fuente con makepkg y luego instalarlo mediante {\color{brown}\texttt{pacman}}.\vspace{5mm}

  El \textbf{AUR} se creó para organizar y compartir nuevos paquetes de la comunidad y para ayudar a acelerar la inclusión de paquetes populares en el repositorio extra.\vspace{5mm}

	La aplicación que usaremos para instalar paquetes de los repositorios de \textbf{AUR} será {\color{brown}\texttt{yay}}.
