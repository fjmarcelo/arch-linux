# Instalación de Arch Linux

<div align="center">
  <img src="img/arch_linux.png" alt="Arch Linux" width="200"/>
</div>

Guía de instalación de **Arch Linux** paso a paso, desde la descarga de la ISO hasta la configuración final del sistema.

---

## Estructura de la guía

| Fase | Pasos |
|------|-------|
| **Preparación** | Descargar la ISO, configurar teclado, detectar modo de arranque, comprobar internet |
| **Instalación** | Particionado, instalación del sistema base, generación del fstab |
| **Configuración** | Zona horaria, localización, red, usuarios, microcode, GRUB |
| **Post-instalación** | AUR, yay, entornos gráficos |

!!! tip "Documentación oficial"
    En caso de dudas, consulta la [wiki de Arch Linux en español](https://wiki.archlinux.org/title/Main_page_(Español)).
