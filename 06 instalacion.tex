\section{Instalación del sistema base}

\subsection{Optimizar los mirrors}

Antes de instalar, optimizamos la lista de mirrors para usar los más rápidos y cercanos.
Esto hace que \texttt{pacstrap} sea mucho más rápido, especialmente en Canarias o conexiones lentas.

\begin{tcolorbox}[title=Seleccionamos los mirrors más rápidos de España]
\begin{lstlisting}[style=bashstyle]
reflector --country Spain --sort rate --save /etc/pacman.d/mirrorlist
\end{lstlisting}
\tcblower
\scriptsize \texttt{reflector} consulta y ordena los mirrors por velocidad y guarda el resultado en \texttt{/etc/pacman.d/mirrorlist},
que es el fichero que usa \texttt{pacman} (y \texttt{pacstrap}) para las descargas.
Si estás en Canarias, añade más países: \texttt{--country Spain,France,Germany}
\end{tcolorbox}

\subsection{Actualización del catálogo de paquetes}
\begin{tcolorbox}[title=Primero actualizamos el catálogo de paquetes]
    \begin{lstlisting}[style=bashstyle]
    pacman -Sy
    \end{lstlisting}
\end{tcolorbox}

\subsection{Instalación}

\begin{tcolorbox}[title=Instalación del sistema base]
\begin{lstlisting}[style=bashstyle]
pacstrap -K /mnt base base-devel linux linux-firmware sudo ntfs-3g networkmanager curl aria2 zsh neovim grub sddm plasma openssh git
\end{lstlisting}
\tcblower
\small Si el arranque es \textbf{UEFI}, instala también \tazul{efibootmgr}:\quad\orden{pacman -S efibootmgr}
\end{tcolorbox}


\subsection{Paquetes instalados}
\begin{tcolorbox}[title=\faExclamation\hspace*{1em} Explicación de los paquetes instalados]

  \small
  \begin{paquetes}
    \item[base:] Conjunto mínimo de paquetes para definir una instalación básica de Arch Linux.
    \item[base-devel:] Conjunto de paquetes necesarios para crear software a partir del código fuente.
    \item[linux:] El propio \textit{kernel}.
    \item[linux-firmware:] Controladores para hardware común.
    \item[sudo:]  Quieres ejecutar comandos como root, ¿verdad?
    \item[ntfs-3g:]  Controlador del sistema de archivos NTFS y utilidades necesarias para trabajar con unidades NTFS.
    \item[networkmanager:] Facilita detección y configuración para que los sistemas se conecten automáticamente a las redes.
    \item[curl:] Herramienta de línea de comandos y una biblioteca para transferir datos mediante URL.
    \item[aria2:] aria2 es una ligera utilidad de descarga multiprotocolo y multifuente.
    \item[zsh:] \textit{Shell} potente que funciona como shell interactivo y como intérprete de lenguajes de scripting.
    \item[neovim:] Editor de texto plano de gran potencia.
    \item[grub:] Gestor multiarranque (válido tanto para BIOS como para UEFI).
    \item[efibootmgr:] Herramienta para gestionar las entradas de arranque EFI (solo necesaria en instalaciones UEFI).
    \item[sddm:] Gestor de sesión gráfico (\textit{Simple Desktop Display Manager}).
    \item[plasma:] Entorno de escritorio KDE Plasma.
    \item[openssh:] Protocolo de red para iniciar una sesión en una máquina remota.
    \item[git:] Programa para control de versiones.
  \end{paquetes}
\end{tcolorbox}
